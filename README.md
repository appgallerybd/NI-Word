# NI-Word — ওয়ার্ড এডিটর

কোনো সার্ভার বা ইন্টারনেট ছাড়াই ব্রাউজারে চলে। `index.html` খুললেই হবে।

## ফিচার
- ফরম্যাটিং: ফন্ট, সাইজ, Bold/Italic/Underline/Strike, Super/Subscript, রঙ, হাইলাইট, শিরোনাম স্টাইল, ফরম্যাট মুছা
- প্যারাগ্রাফ: অ্যালাইনমেন্ট, লিস্ট, ইন্ডেন্ট, লাইন স্পেসিং, RTL (আরবি/উর্দু)
- ইনসার্ট: টেবিল (সারি/কলাম যোগ-বাদ), ছবি, লিংক, রেখা, পেজ ব্রেক
- **পেজ ভাগ:** A4 পেজ আলাদা আলাদা দেখায়, কনটেন্ট স্বয়ংক্রিয়ভাবে পরের পেজে যায় (ব্লক-স্তরে), পেজ ব্রেক মানে, মোট পেজ সংখ্যা দেখায়
- খুঁজুন ও বদলান, মার্জিন, জুম, প্রিন্ট/PDF
- অটোসেভ (IndexedDB), একাধিক ডকুমেন্ট
- **আসল .docx এক্সপোর্ট ও ইম্পোর্ট** (বাইরের লাইব্রেরি ছাড়া), সাথে .doc, HTML, টেক্সট

## ফাইল
`index.html` · `css/style.css` · `js/app.js` (এডিটর) · `js/docx.js` (DOCX) · `js/zip.js` (ZIP) · `js/storage.js` · `js/icons.js`

## সীমাবদ্ধতা
পেজ ভাগ ব্লক (অনুচ্ছেদ/টেবিল) পর্যন্ত, এক অনুচ্ছেদের মাঝখানে পেজ ভাঙে না; হেডার/ফুটার, ইম্পোর্টে ছবি ও লিস্টের নম্বর এখনো নেই।
